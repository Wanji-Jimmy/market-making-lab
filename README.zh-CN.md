# 做市模拟器

**为什么做市商赚到了买卖差价，账户还是可能亏钱？**

这是一个用 Python 学习报价、现金和库存的小项目。先比较两个简单规则：

| 规则 | 怎么报价 |
| --- | --- |
| 固定价差 | 报价跟着参考价移动，买卖价差保持不变。 |
| 根据库存调整 | 库存太多时，同时降低买价和卖价，鼓励卖出；持有负库存时反过来。 |

两种策略面对相同的模拟市场和客户，账本记录每次成交、库存、成本和盈亏。

## 先看一个能手算的例子

使用 Python 3.10 或以上版本，无需安装额外库。在项目目录运行：

```bash
python3 lesson.py
```

程序逐步展示五个预设事件。本例不收手续费：

| 盈亏来源 | 模拟货币单位 |
| --- | ---: |
| 成交价格相对参考价的优势 | +2.70 |
| 库存价格变化 | −6.00 |
| 清仓前的账面盈亏 | **−3.30** |

这个例子说明：赚到差价，仍然要承担手中库存的价格风险。另一组下跌情景中，库存调整减少了平均亏损，但两种策略仍然都亏损。[查看情景结果](results/研究结果.md)

先读 [lesson.py](lesson.py)，再看 [simulator.py](simulator.py) 中的报价、成交和账本函数。面试主线先讲清这三件事即可：**怎么报价、成交后钱和库存怎么变、为什么最后可能亏损。**

基础市场和成交都是模拟的。报价被限制在参考价两边，没有订单簿和排队模型，不能把结果当作真实交易盈利。
