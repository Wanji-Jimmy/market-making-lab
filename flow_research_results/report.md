# 从成交流量到报价：冻结后的测试结果

本报告把两个问题分开：上一段主动成交量能否改善下一段成交价变化的预测；把这一预测用于报价后，在明确假设的成交环境中会发生什么。**价格和方向来自公开历史记录，客户意愿、数量、路由和我们的成交是假设；以下PnL不是USDT收益或真实历史成交回测。**

## 本轮结论

截断线性模型在这三个测试日的池化MSE低于两个固定基线。 模型减零预测为 -0.008195 bp²，模型减训练均值为 -0.008201 bp²；负值才表示误差较低。 相对零预测，**MSE变化-0.5087%，MAE变化+10.5502%**（MAE从0.637356变为0.704599bp）。 两种误差指标方向相反，不能概括为预测全面改善。

在五个意愿种子的主实验中，先在每天内平均，再对三个日期等权：flow相对库存策略的平均PnL差为 **+0.920309**；相对仅截距策略为 **+0.744560**。两种比较必须同时读：前者包含完整信号，后者进一步分离imbalance斜率。

这一增量并非每日一致：**3个测试日中有1天flow减库存策略的日均差为负**（2025-09-07）。flow的平均最大回撤为1.9552，库存策略为1.9359，差为+0.01928；正值表示这项风险指标变差。

简单加宽对照的主平均PnL为154.0524，高于flow的127.9396。但把假设意愿均值降为1.5bp后（同为种子7001），加宽对照为57.6238，低于flow的68.2047；此时flow减库存策略也为-0.43995。**没有一个在这些条件下始终占优的策略，效果依赖日期和人工意愿假设。**

这是已声明日期、参数和假设下的描述性结果。没有根据测试结果选择赢家、重新调参或构造种子置信区间；正的模拟PnL差额也不构成现实盈利证据。

## 特征、模型与预测评价

在决策时点t，特征来自 `[t−5s,t)` 的主动买卖ETH成交量差除以总量。参考价为严格早于t的最后成交价；目标为 `[t,t+5s)` 最后成交价相对参考价的变化（bp）。二者都不是观察到的中间价。只保留同日相邻两桶都有成交的行，不跨日、不向前填充缺失桶。

训练行数 **51,817**。冻结模型：

```text
raw predicted return (bp) = 0.0080421135 + (0.2216479781) × imbalance
quote signal (bp) = clip(raw predicted return, -2, +2)
training-mean baseline (bp) = 0.0026502613
```

在imbalance∈[−1,1]内，冻结线性模型的预测范围为[-0.213606, 0.229690]bp。这完全落在±2bp以内，因此本轮原值与截断结果相同；不能把表现归功于截断。

## 五种报价策略的假设环境实验

每个日期的首个有效参考价归一化为100，初始现金10000、库存0，单次交易一单位，库存上限±10。价差、信号、库存偏移和费用按当前归一化参考价的bp计算；固定价格tick为0.0001。跨日期不延续库存。

主实验成交费用为0.25bp，客户意愿距离服从均值3bp的指数分布。下一桶首笔实际主动成交方向只用来确定假设客户买/卖；其价格底线、数量、向本做市商路由及执行都不是历史观察值。五种策略在相同日期和种子下共享预生成环境。

假设成交被放在桶起点，随后持有库存五秒，没有使用实际首笔主动成交在桶内的具体时刻。缺失决策区间不发生成交，但保留库存并补计参考价变化。末尾在最后可用的下一参考价处按1bp＋成交费清仓，该时点不一定是UTC日末。

## 配对差额与盈亏分解

每个差额都是同日、同意愿种子的 `flow − 对照`，随后先日内平均、再日期等权。费用和清仓两列已取负号，因而各贡献可以直接相加：

```text
ΔPnL = Δ成交优势 + Δ库存重估 − Δ成交费用 − Δ清仓成本
```

库存重估同时包含桶内与缺失区间。分项是代数记账归因，不是互相独立的因果效应；成交客户与成交数变化也影响各项。

为什么加宽报价可能在这里占优？只看一个极简机会：库存为0、参考价不变、忽略tick/清仓及后续持仓风险，客户意愿距离U服从均值u的指数分布。半价差h的接受概率就是exp(−h/u)，因此每个机会的毛成交优势为h×exp(−h/u)；每笔费用为f时，净值为(h−f)×exp(−h/u)。在这些限制条件下，它在h=u+f处达到最大。

这解释了本模型为何会机械地偏好某些宽度：主参数u=3bp、f=0.25bp，与低意愿u=1.5bp提供不同的取舍。它不是经验估计、完整库存策略的最优解或现实报价建议。**正的总体PnL首先依赖模型给出的意愿分布与包围参考价的报价约束，不能用其大小为真实信号背书。**
